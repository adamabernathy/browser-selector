The old way vs. the toast way.

Without Browser Toast

  1. Open System Settings
  2. Navigate to Desktop & Dock
  3. Scroll to Default web browser
  4. Select from dropdown
  5. Close System Settings

With Browser Toast

  1. Click the menu bar icon
  2. Pick a browser
  3. Done

Five steps become one.
